# kit/ — the AVEN operator kit

Machine-readable brand. The website build, collateral templates and any AI agent should read from here, not from screenshots of the book.

| File | What | Who consumes it |
|---|---|---|
| `tokens.json` | colours (hex + role), type stacks + aliases, scale, line weights, taglines | website CSS build, design tools, agents |
| `tokens.css` | the same as `:root` custom properties — generated by `src/build.py tokens`, do not edit | website, any HTML |
| `voice.json` | registers, core rules, flex dials per channel, nevers, channel defaults, the lines | content agents, copywriting, social scheduling |
| `brand.md` | one-page prose brief | paste into a system prompt or a human brief |
| `marks/*.svg` | every candidate mark, wordmark text outlined to paths (font-stable) | print, web, embroidery vendors |
| `marks/candidates/` | the wordmark set in each candidate serif — for the type decision only | brand book type card |

## How to use it

- **CSS:** `<link rel="stylesheet" href="kit/tokens.css">` then use `var(--pine)`, `var(--font-serif)` etc. The font aliases `AVEN Serif` / `AVEN Sans` resolve via `assets/fonts/fonts.css`.
- **Agents:** load `brand.md` as the brief and `voice.json` for the rules; choose the register from `channel-defaults`; never use a word in `never`.
- **Marks:** use the files in `marks/` as-is. Do not re-type the wordmark — it is outlined on purpose so it renders identically everywhere. After the final mark is chosen, the vector suite (print, web, embroidery, favicon cut) is added here.

## Regenerate

```
python src/build.py tokens   # tokens.json -> tokens.css
python src/build.py fonts    # fetch latin woff2 + write fonts.css
python src/build.py marks    # outline src/marks/*.svg -> kit/marks/
```

Edit marks in `src/marks/` (live `<text>`), never in `kit/marks/`.
